Personal Drive Uploader

個人利用のファイル転送ツール / A personal file transfer tool

概要

Personal Drive Uploader は、開発者本人が自分のPC上の音声ファイルを、自分の Google ドライブへ転送するために作成した個人利用のツールです。転送には、オープンソースのコマンドラインツール rclone と Google Drive API を使用しています。

機能

  • ローカルの指定フォルダにあるファイルを、自分の Google ドライブの指定フォルダへアップロードする
  • アップロードが正常に完了したファイルを、ローカルから削除する

利用範囲

本ツールは、開発者本人のみが自分の Google アカウントで使用します。一般公開サービスではなく、第三者による利用や、第三者のデータの取得は想定していません。Google ドライブの認証情報(OAuth トークン)は、本人のPC内の rclone 設定ファイルにのみ保存され、外部サーバーへは送信されません。

Overview

Personal Drive Uploader is a personal-use tool built by its developer to upload the developer's own podcast audio files from a local PC to the developer's own Google Drive. It uses the open-source command-line tool rclone and the Google Drive API. It is used only by the developer with the developer's own Google account. It is not a public service, and OAuth tokens are stored only in the rclone configuration file on the developer's own computer.
