プライバシーポリシー

Personal Drive Uploader / 最終更新日: 2026年11月22日

1. 適用範囲

本ポリシーは、個人利用ツール「Personal Drive Uploader」(以下「本アプリ」)における、Google ユーザーデータの取り扱いを説明するものです。本アプリは、開発者本人が自分の Google アカウントでのみ使用します。

2. アクセスするGoogleユーザーデータ

本アプリは、Google OAuth 2.0 を通じて、次のアクセス権限を要求します。

  • https://www.googleapis.com/auth/drive:Google ドライブ内のファイルの作成、閲覧、削除(ファイルのアップロードと管理のため)
  • https://www.googleapis.com/auth/drive.metadata.readonly:ファイル名などのメタデータの閲覧(転送先フォルダの確認のため)
  • https://www.googleapis.com/auth/docs:rclone の標準的な設定に含まれる権限

3. データの利用目的

取得したアクセス権限は、ローカルPC上の音声ファイルを、本人の Google ドライブの指定フォルダへアップロードする目的にのみ使用します。広告、マーケティング、分析、その他の目的には一切使用しません。

4. データの保存・共有・送信

  • OAuth トークンは、開発者本人のPC内の rclone 設定ファイルにのみ保存されます。
  • 本アプリは独自のサーバーを持たず、Google ユーザーデータを開発者のサーバーや第三者へ送信、販売、共有することはありません。
  • ファイルの内容は、本人のPCと Google ドライブの間でのみ転送されます。
  • 人間が Google ユーザーデータを閲覧することはありません(開発者本人が自分のデータを利用する場合を除く)。

5. データの保持と削除

ドライブ上のファイルは、本人が Google ドライブ上で管理・削除できます。アクセス権限は、Google アカウントの「サードパーティによるアクセス」からいつでも取り消せます。取り消した場合、またはPC上の rclone 設定ファイルを削除した場合、本アプリは Google ドライブへアクセスできなくなります。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

Google API から受け取った情報の利用および他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

7. ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改訂します。

Privacy Policy

Personal Drive Uploader / Last updated: November 22, 2026

1. Scope

This policy describes how "Personal Drive Uploader" (the "App") handles Google user data. The App is used only by its developer, with the developer's own Google account.

2. Google user data accessed

The App requests the following access through Google OAuth 2.0:

  • https://www.googleapis.com/auth/drive: to create, view, and delete files in Google Drive, in order to upload and manage files.
  • https://www.googleapis.com/auth/drive.metadata.readonly: to view file metadata such as names, in order to confirm the destination folder.
  • https://www.googleapis.com/auth/docs: included in the standard rclone setup.

3. How the data is used

Access is used solely to upload audio files from the developer's local computer to a designated folder in the developer's own Google Drive. It is not used for advertising, marketing, analytics, or any other purpose.

4. Storage, sharing, and transfer

  • OAuth tokens are stored only in the rclone configuration file on the developer's own computer.
  • The App operates no server of its own and does not transmit, sell, or share Google user data with the developer's servers or any third party.
  • File contents are transferred only between the developer's computer and Google Drive.
  • No humans read Google user data, other than the developer accessing the developer's own data.

5. Retention and deletion

Files in Google Drive can be managed and deleted by the account owner at any time. Access can be revoked at any time from Google Account third-party access settings. Once access is revoked, or the rclone configuration file is deleted, the App can no longer access Google Drive.

6. Compliance with the Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Changes to this policy

If this policy changes, this page will be updated and the "Last updated" date revised.
